# 纸面自检四问 · 动作卡

> **用途**：`W1-启动清单-Go主线.md` §2.4 的第三条规矩「写完自检四问：变量 → 边界 → 返回值 → 复杂度」的**可执行版**。那里只说"要自检"，没说"具体怎么查"——这一页就是"怎么查"。
> **什么时候用**：纸上 / 白板写题之后、交卷之前。没有编译器、没有补全、不能"跑一下看看"，这 4 分钟就是你自己当编译器。
> **示例**：全篇用题 1「两数之和」的暴力解举例（`playground/p001_two_sum/main.go`）。

---

## 总览：四问 = 四个动作（不是"心里想一想"）

| 顺序 | 动作 | 花多久 | 口诀 |
|---|---|---|---|
| 1 · 变量 | **逐个划**：声明了？用了？类型对？ | 30 秒 | 声明了不用 = 编译失败 |
| 2 · 边界 | **五类各写一个具体输入**，手指走一遍 | 2 分钟 | 空、单、最大、特殊、重复、末尾 |
| 3 · 返回值 | **手指沿每条路径走**，找 return | 30 秒 | 循环之后还有路，必须兜底 return |
| 4 · 复杂度 | **数循环层数 + 数新申请的内存** | 1 分钟 | 几层循环跟着 n 走 |

---

## 第一问 · 变量

拿笔把每个变量名划一遍，问三件事：

1. **声明了、用了吗？** Go 的硬规则：**局部变量声明了不用 = 编译错误**（Java 只是警告，转过来最容易忘）。
2. **名字被内层遮住了吗？**（shadow：内层又写一次同名变量）
3. **类型对吗？** `len(nums)` 返回 `int`，所以 `i < len(nums)` 不用转换；但 `int32` 与 `int` 相加必须显式 `int(x)`。

**题 1 实例**：`i`、`j` 都用到 ✅；`j := i + 1` 起止正确（这是本题最容易写错的地方）✅。
**常见翻车**：`x := 1` 之后又写 `x := 2`（`:=` 左边至少要有一个新变量）；声明了 `sum := 0` 却没用。

## 第二问 · 边界（五类，每类写**具体输入**，别只想"应该没问题"）

| 类别 | 题 1 的输入 | 手算结果 |
|---|---|---|
| 最小 · 空 / nil | `twoSum(nil, 9)`、`twoSum([]int{}, 9)` | 循环一次都不进 → `nil` |
| 最小 · 单元素 | `twoSum([]int{5}, 5)` | 内层不执行 → `nil` |
| 最大 | n = 10⁴ 且无解 | 约 **5×10⁷** 次比较（留给第四问判超时） |
| 特殊值 | `[-1,-2,-3,-4,-5], -8`；`target = 0`；`[0,4,3,0], 0` | `[2 4]`；`[0 3]` |
| 重复 | `[3,3], 6` | **`[0 1]`，绝不能是 `[0 0]`** |
| 答案位置 | 末尾：`[1,2,3,4,5], 9` | `[3 4]` |

**手算方法**：把输入抄下来，用手指当 `i` / `j` 走**前两轮 + 最后一轮**。只在脑子里"感觉没问题"等于没查。

> 题 1 的题目本身保证「一定有解、len ≥ 2」，所以上面第一、二行的 `nil` 路径是**兜底**而不是功能——但你必须知道它会返回什么、会不会 panic。

## 第三问 · 返回值

1. 签名承诺返回什么类型？**每条 `return` 的类型都对吗？**
2. **每条执行路径都有 return 吗？** 方法：把每个 `for` / `if` 都当成"**可能一次都不执行**"，然后看还剩没有 return。
   - 外层 `for` 能一次都不进吗？（能，len = 0）→ 那函数会掉到哪？→ 掉到函数末尾 → **`missing return`，编译不通过**。
   - 口诀：**循环之后永远还有一条路，所以循环外面必须有兜底 return。**
3. 找不到答案时返回什么？`nil` 还是 `[]int{}`？—— 两者 `fmt.Println` 打印出来一样（都是 `[]`），但 `reflect.DeepEqual` 判定**不相等**，写测试时要注意。
4. 有没有"该 `return` 却写成 `fmt.Println`"？（纸面高频错误）

**题 1 实例**：`return []int{i, j}` 类型正确 ✅；循环外 `return nil` 兜底 ✅（第一次写时漏了这条 → 编译器直接报 `missing return`）。

## 第四问 · 复杂度

**时间** = 数"几层循环跟着 n 走"：单层 → O(n)；两层都跟 n → O(n²)；循环里查一次 map → O(n)。
**空间** = 数"除了入参以外，你新申请了什么"：只用了几个计数器 → O(1)；开了 `map` / 新切片跟 n 一样长 → O(n)。

| n | O(n) | O(n²) |
|---|---|---|
| 10² | 100 | 10⁴ |
| 10³ | 1 千 | 10⁶ |
| 10⁴ | 1 万 | 约 5×10⁷ |
| 10⁵ | 10 万 | 约 5×10⁹（**必超时**） |

**题 1 实例**：时间 **O(n²)**、空间 **O(1)** → n ≤ 10⁴ 时 0.1 秒级，**能 AC**；但题目有进阶要求「时间小于 O(n²)」，标准解法是哈希版 **O(n) / O(n)**。
**答题话术**：一句话说完 —— **"时间 O(n²)，空间 O(1)"**。

## 收尾：纸角两行

```text
卡点：
复杂度：时间 O(?) 空间 O(?)
```

- 「卡点」写**当时卡住你的那件事**，不是题解思路。题解网上到处都是，**这一栏才是只属于你、网上搜不到的东西**——两周后重做时它最值钱。
