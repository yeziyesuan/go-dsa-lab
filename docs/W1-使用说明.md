## 2. 语法点的学法（周一–周四上午，3 块 × 50 分钟）

`syntax/` 里 12 个目录就是 12 个语法点，**顺序就是学习顺序**：

```
01_types → 02_control → 03_slice → 04_map → 05_func → 06_pointer
→ 07_struct_method → 08_interface → 09_error → 10_package → 11_concurrency → 12_stdlib
```

每一块 50 分钟这样用：

1. **15 分钟**看资料（[资料索引](W1-资料索引.md) 里挑一个，别贪多）。
2. **25 分钟**：打开 `syntax/xx_yyy/main.go` 看懂 → **关掉它** → 在 **`playground/`** 里凭记忆重敲一遍（手打，不许复制粘贴），改几个值、故意写错一次看编译器骂什么。
   ```powershell
   mkdir playground\01_vars
   code playground\01_vars\main.go
   go run ./playground/01_vars
   ```
   > `syntax/` 和 `problems/` 里的代码是**参考资料，不要在上面改**；自己的练习一律写进 `playground/`
   > （约定见 [playground/README.md](../playground/README.md)）。这个目录**要提交**——它是你"每天都在写代码"的证据。
3. **10 分钟**：在 `notes/` 里用**自己的话**写 3–5 行「这个语法点最反直觉的地方」，然后 `go run ./syntax/xx_yyy` 确认还能跑。

**只看不写等于没学。** 三个必须亲手复现的坑：

- `03_slice`：切片共享底层数组 —— `s1 := []int{1,2,3}; s2 := s1[:2]; s2 = append(s2, 9)`，看 `s1` 变了什么。
- `04_map`：往 nil map 里写会 panic，必须 `make`。
- `09_error`：`errors.Is` 与 `==` 的区别（包装过的错误用 `==` 比不出来）。
