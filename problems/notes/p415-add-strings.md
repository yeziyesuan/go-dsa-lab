# 415. 字符串相加

- 难度 / 类型：简单 · 字符串 / 模拟竖式
- 思路（一句话）：从两个串的末尾往前走，逐位相加并维护进位，生成的低位先入缓冲，最后整体反转。
- 复杂度：时间 O(max(m, n))，空间 O(max(m, n))
- 卡点：
  1. 循环条件 `i >= 0 || j >= 0 || carry > 0` 三个条件缺一不可。少了 `carry` 会丢掉最高位进位：`"99" + "1"` 算成 `"00"`（正确 `"100"`）。
  2. 两串长度不同时，短的一侧在 `i`/`j` 小于 0 时要补 0，不能越界取值。
  3. 结果是从低位往高位生成的，**最后必须反转**，忘了就得到倒过来的答案。
  4. 结果字符要写 `byte('0'+sum%10)`；直接写 `sum%10` 会得到不可见的控制字符。
  5. `"0" + "0"` 要返回 `"0"` 而不是 `""`，靠 `i >= 0` 这个条件保证循环至少跑一次。
- Go 注意点（为什么不用 `strconv.Atoi` / `ParseInt`）：
  - 它们的结果受 `int64` 限制（`Atoi` 得到 `int`，64 位平台也是 64 位，上限约 9.2e18，19 位）。题目给的是任意长度数字串，几百位很常见，`ParseInt` 会返回 `ErrRange`；改用 `ParseFloat` 又会丢精度 —— 从根上就不该把这些串转成数字。
  - 竖式加法逐位处理，耗时只和位数有关，天然支持任意长度，这也是「大数运算」的基本功。
  - 字符转数字用 `c - '0'`；`byte` 相减仍是 `byte`，参与算术前要显式转 `int`，否则 `byte + byte` 会按 `uint8` 回绕（`'9' + '9'` 得到 0x12 而不是 18）。
  - 缓冲区用 `make([]byte, 0, n+1)` 预留容量，避免 `append` 过程中反复扩容；`n+1` 是给最高位进位留的位置。
- 关键代码片段：

```go
for i >= 0 || j >= 0 || carry > 0 {
	sum := carry
	if i >= 0 {
		sum += int(num1[i] - '0')
		i--
	}
	if j >= 0 {
		sum += int(num2[j] - '0')
		j--
	}
	buf = append(buf, byte('0'+sum%10))
	carry = sum / 10
}
```
