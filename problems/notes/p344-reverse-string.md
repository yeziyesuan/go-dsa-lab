# 344. 反转字符串

- 难度 / 类型：简单 · 双指针 / 原地交换
- 思路（一句话）：左右双指针从两端向中间走，边走边交换 `s[i]` 与 `s[j]`，直到两指针相遇。
- 复杂度：时间 O(n)，空间 O(1)（不分配任何额外数组）
- 卡点：
  1. 循环条件写 `i < j`。写成 `i <= j` 时中间元素会自己和自己交换，结果虽然对，但多做一次无意义操作。
  2. 双指针的推进不能写成 `i++, j--`：Go 的 `for` 后置语句只允许一条语句，必须写成并行赋值 `i, j = i+1, j-1`。
  3. 参数得是 `[]byte` 才能原地改：`string` 不可变；`[N]byte` 数组是值传递，函数里改了外面看不见。
  4. 别顺手用 `for i, j := 0, len(s)-1; ...` 里的 `j` 去做别的下标计算，`j` 是 `int`，越界时是运行期 panic 而不是编译错误。
- Go 注意点：
  - `s[i], s[j] = s[j], s[i]` 是 Go 的并行赋值，天生就是交换，不需要临时变量，也不会出现「先覆盖后赋值」的经典错误。
  - `[]byte` 是引用底层数组的切片（指针 + 长度 + 容量），函数内的修改直接影响调用方 —— 这正是「原地」能成立的原因。
  - 按 byte 反转只对 ASCII 安全。中文是多字节 UTF-8，按字节反转会把编码打乱，得到非法 UTF-8；但「反转两次还原」这条性质仍然成立（测试里固定了这两点）。要按字符反转必须先 `[]rune(s)`。
- 关键代码片段：

```go
func ReverseString(s []byte) {
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
}
```
