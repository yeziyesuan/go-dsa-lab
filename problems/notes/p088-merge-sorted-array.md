# 88. 合并两个有序数组

- 难度 / 类型：简单 · 双指针（三指针）/ 原地归并
- 思路（一句话）：`i` 指 `nums1` 有效段末尾、`j` 指 `nums2` 末尾、`k` 指 `nums1` 写位置末尾，每轮把较大的写到 `nums1[k]`，**从后往前**推进。
- 复杂度：时间 O(m+n)，空间 O(1)
- 卡点：这题唯一的考点就是**方向**——从前往后归并会把 `nums1` 里还没读的元素覆盖掉。必须从后往前，因为 `k >= i` 恒成立，被写的位置永远是已搬走或本来就是占位符的区域。第二个坑是把 `nums1` 的长度当成 `m`（实际是 `m+n`），导致写位置和末尾指针都差 `n`。第三个坑是收尾：`j >= 0` 时要把 `nums2` 剩下的补到前面，而 `i < 0` 那半边不需要任何收尾，很容易多写一个无用循环或者干脆漏掉该写的那个。
- Go 注意点：`m == 0` 时绝不能写 `nums1 = nums2`——那只是换了函数内的切片头，调用方毫无感知；必须逐个 `nums1[k] = nums2[j]`。同理 `append` 可能重新分配底层数组，修改会全丢在函数里，这题要的就是写回原底层数组。收尾也可以直接用 `copy(nums1[:j+1], nums2[:j+1])`，等价且更短。
- 关键代码片段：

```go
i, j, k := m-1, n-1, m+n-1
for i >= 0 && j >= 0 {
	if nums1[i] > nums2[j] {
		nums1[k] = nums1[i]
		i--
	} else {
		nums1[k] = nums2[j]
		j--
	}
	k--
}
for j >= 0 {
	nums1[k] = nums2[j]
	j--
	k--
}
```
