# 11. 盛最多水的容器

- 难度 / 类型：中等 · 双指针（相向夹逼）/ 贪心
- 思路（一句话）：左右指针从两端向中间走，每轮用 `min(h[l], h[r]) * (r-l)` 更新答案，然后移动**较短**的那一边。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：第一，面积公式写成 `(h[l] + h[r]) * (r-l)`（忘了短板效应），示例 1 会得 13 而不是 49。第二，移动方向写反成移动较长边——这是主动丢解。第三，`h[l] == h[r]` 时纠结该动哪边，其实两边都安全，统一走 `else` 即可。
- 为什么移动短边不会漏解：设 `h[l] <= h[r]`。固定 `l`，右端点取任何 `r' <= r`，面积 `min(h[l], h[r']) * (r'-l) <= h[l] * (r'-l) <= h[l] * (r-l)`，也就是当前这轮的 `(l, r)` 已经是以 `l` 为左端点的**上界**。既然 `l` 的最优可能已经被穷尽并记录，`l` 就可以安全淘汰（`l++`）；反之若移动 `h[r]` 那一边，`l` 的最优解还没穷尽就被跳过了，会漏解。
- Go 注意点：Go 没有三目运算符，取较小值要老老实实 `h := height[l]; if height[r] < h { h = height[r] }`；Go 1.21+ 有内置 `min`，但 W1 统一手写避免版本差异。循环条件用 `l < r` 而不是 `l <= r`，相等时宽度为 0、面积无意义。这题 O(1) 空间是卖点，不要造辅助切片。
- 关键代码片段：

```go
for l < r {
	h := height[l]
	if height[r] < h {
		h = height[r]
	}
	if area := h * (r - l); area > res {
		res = area
	}
	if height[l] < height[r] {
		l++ // 短边出局，不会漏解
	} else {
		r--
	}
}
```
