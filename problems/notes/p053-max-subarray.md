# 53. 最大子数组和

- 难度 / 类型：中等 · 数组 / 动态规划（Kadane）
- 思路（一句话）：`cur` 表示「以当前元素结尾的最大子数组和」，每个元素要么接在 `cur` 后面、要么自己另起一段，取较大者并顺手更新全局最大。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：全负数数组是分水岭。把 `best`/`cur` 初始化成 0（或者写 `if cur < 0 { cur = 0 }` 时把 `best` 也拖成 0）会让 `[-3,-2,-5]` 返回 0；而子数组至少含一个元素，正确答案是 `-2`。正确做法是用 `nums[0]` 初始化两个变量。第二个坑是空切片没挡掉，`nums[0]` 直接 panic。第三个坑是两个分支只留一个，退化成「求数组最大值」。
- Go 注意点：用 `nums[0]` 初始化 `best` 和 `cur`，就不用引 `math` 包找哨兵值。Go 1.21+ 有内置 `max`，但 W1 阶段统一手写 `if` 比较，避免记混「内置 `max` 和 `math.Max` 不是一回事」。遍历 `nums[1:]` 是零拷贝的子切片，不产生新数组。
- 关键代码片段：

```go
best, cur := nums[0], nums[0]
for _, x := range nums[1:] {
	if cur+x > x {
		cur += x
	} else {
		cur = x
	}
	if cur > best {
		best = cur
	}
}
return best
```

- 备注：也可用分治（左半 / 右半 / 跨中点各求最优，跨中点从 mid 向两侧扫最大前后缀），O(n log n)；分治版本 W12 再回来看。
