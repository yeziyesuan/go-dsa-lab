# 26. 删除有序数组中的重复项

- 难度 / 类型：简单 · 双指针（快慢指针）/ 原地数组
- 思路（一句话）：慢指针 `k` 指向去重结果的下一个待写位置，快指针 `i` 扫描数组，`nums[i] != nums[k-1]` 就写进 `nums[k]` 并让 `k` 前进。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：空数组没挡掉就是 `nums[k-1]` 越界 panic（`k` 初始 0）。第二个坑是返回值写成 `k+1` 或干脆 `len(nums)`；`k` 本身就是新长度，不加一。第三，把 `k` 同时当下标和计数用时容易混——统一理解成「有效前缀长度 == 下一个待写位置」就不乱了。
- Go 注意点：切片是引用语义，`nums[k] = nums[i]` 直接改底层数组，调用方能看到，所以不需要返回值带新切片。这里必须用下标循环而不是 `for range`，因为 `range` 给的 `v` 是副本，靠它改不了数组。测试里用 `append([]int(nil), tt.nums...)` 拷一份，避免多个子测试共享同一底层数组互相污染。
- 关键代码片段：

```go
if len(nums) == 0 {
	return 0
}
k := 1
for i := 1; i < len(nums); i++ {
	if nums[i] != nums[k-1] {
		nums[k] = nums[i]
		k++
	}
}
return k
```

## 我的卡点（2026/9/22，第一遍自己写的时候）

- **做法**：快慢指针。`i` 从 1 往后扫（读指针），`k` 指向"下一个待写位置"（写指针）；**数组有序 ⇒ 相同值必然相邻**，所以 `nums[i] != nums[i-1]` 就说明遇到了新值 → `nums[k] = nums[i]; k++`。**时间 O(n) / 空间 O(1)**。
  （上面参考解用的是 `nums[i] != nums[k-1]`，跟"最后一个保留的值"比；与本节的 `nums[i-1]` 两种判据等价，都靠"有序"成立。练习代码在 `playground/p026_remove_duplicates/main.go`。）
- **卡点①（初值，最值钱）**：`k` 初值写成 0 → 第一次写入落到 `nums[0]`，**把天然保留的首元素覆盖掉**；输入 `[1]` 时循环一次都不进，直接返回初值 0。
  记法：**`k` 的初值 = "不用比较就已经确定保留的元素个数"**。有序数组的首元素没有"前一个"可比 ⇒ 天然唯一 ⇒ **初值 1**。（题 27 移除元素就没有元素天然保留 ⇒ 初值 0。）
- **卡点②（结构）**：最初 `return k` 写在 `for` 里面，函数还少一个 `}` → 文件连语法都没过（`syntax error: unexpected name main`）。教训：**`return` 必须在循环外**——循环可能一次都不执行（`len == 1`），那条路也得有返回值。
- **卡点③（两个选择题）**：内层该用 `if` 还是 `for`？→ **走数组用 `for`，做判断用 `if`**。判据用"相等"还是"不等"？→ 目标是"遇到新值才写"，所以用 **`!=`**。
- **边界实跑结果**：单元素 / 两个相同 / 两个不同 / 三个相同 / 无重复 / 负数重复 / 全 0 / 末尾重复 / n=30000（每 3 个重复 → k=10000）**全部通过**；空输入（题目约束 `len >= 1`，不会发生）会返回 1，想更稳可在开头加 `if len(nums) == 0 { return 0 }`。
- **可复用的模板**：`k := 1` 慢指针 + `for i := 1; ...` 快指针 + `if 判据 { nums[k] = nums[i]; k++ }`。换题只改两处：**`k` 的初值**和 **`if` 的判据**（27 移除元素、283 移动零、88 合并都是这个骨架）。
