# 26. 删除有序数组中的重复项

- 难度 / 类型：简单 · 双指针（快慢指针）/ 原地数组
- 思路（一句话）：慢指针 `k` 指向去重结果的下一个待写位置，快指针 `i` 扫描数组，`nums[i] != nums[k-1]` 就写进 `nums[k]` 并让 `k` 前进。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：空数组没挡掉就是 `nums[k-1]` 越界 panic（`k` 初始 0）。第二个坑是返回值写成 `k+1` 或干脆 `len(nums)`；`k` 本身就是新长度，不加一。第三，把 `k` 同时当下标和计数用时容易混——统一理解成「有效前缀长度 == 下一个待写位置」就不乱了。
- Go 注意点：切片是引用语义，`nums[k] = nums[i]` 直接改底层数组，调用方能看到，所以不需要返回值带新切片。这里必须用下标循环而不是 `for range`，因为 `range` 给的 `v` 是副本，靠它改不了数组。测试里用 `append([]int(nil), tt.nums...)` 拷一份，避免多个子测试共享同一底层数组互相污染。
- 关键代码片段：

```go
if len(nums) == 0 {
	return 0
}
k := 1
for i := 1; i < len(nums); i++ {
	if nums[i] != nums[k-1] {
		nums[k] = nums[i]
		k++
	}
}
return k
```
