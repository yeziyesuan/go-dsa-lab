# 27. 移除元素

- 难度 / 类型：简单 · 双指针（快慢指针）/ 原地数组
- 思路（一句话）：慢指针 `k` 是下一个待写位置，快指针 `i` 扫一遍，`nums[i] != val` 就写进 `nums[k]` 并让 `k` 前进，等于 `val` 的直接跳过被后面的元素覆盖。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：`k` 初值写成 1（从 26 题搬过来惯性太大）会白白多留首个元素；判断条件写反成 `== val` 会把该删的全留下。另外返回值是 `k` 而不是 `len(nums)`——题目只保证 `nums[:k]` 里没有 `val`，`k` 以后是垃圾数据，断言整条切片必挂。
- Go 注意点：`nums[k] = nums[i]` 里 `k <= i` 恒成立，所以原地覆盖不会踩掉未读元素，不用额外数组。切片传参是描述符拷贝，函数内改元素调用方可见、重新赋值 `nums = ...` 则不可见。测试里 `append([]int(nil), tt.nums...)` 拷一份再跑，避免子测试共享底层数组互相污染。
- 关键代码片段：

```go
k := 0
for i := 0; i < len(nums); i++ {
	if nums[i] != val {
		nums[k] = nums[i]
		k++
	}
}
return k
```
