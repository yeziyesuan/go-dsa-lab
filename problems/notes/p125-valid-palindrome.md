# 125. 验证回文串

- 难度 / 类型：简单 · 双指针 / 字符串
- 思路（一句话）：左右指针相向而行，各自跳过非字母数字字符，再把两边统一成小写后比较。
- 复杂度：时间 O(n)，空间 O(1)（不构造「过滤后」的新字符串）
- 卡点：
  1. 跳过无效字符必须跳到有效为止（`continue` 回去重新判断）。只 `if` 一次就往下走，遇到 `"a,,,a"` 这类连续标点会拿标点去比较，直接判错。
  2. 忽略大小写要显式限定在字母范围内（只有 `'A'-'Z'` 才转小写）。用「两字符差 32」「较小的一边加 32」这类技巧会把数字误判成字母：`'0'`(48) 与 `'P'`(80) 恰好差 32，于是 `"0P"` 被错判成回文 —— 本题最经典的陷阱。
  3. 循环条件 `i < j`；遇到 `i == j` 就结束（单个字符不用比）。
  4. 过滤后为空（`""`、`" "`、`".,!"`、`"中文"`）按题目定义都返回 `true`，别特判成 `false`。
- Go 注意点（byte vs rune，本题重点）：
  - `byte` = `uint8`，表示**一个字节**；`rune` = `int32`，表示**一个 Unicode 码点**。Go 的 `string` 底层是只读字节序列，`s[i]` 取的是第 i 个**字节**，不是第 i 个字符。一个汉字在 UTF-8 里占 3 个字节，`"中"[0]` 是 `0xE4`，单独看没有意义。
  - **本题用 byte 遍历是安全的**：只需要比较 ASCII 字母数字，而 ASCII 字符在 UTF-8 中恒为单字节（0x00–0x7F），绝不可能是多字节字符的续字节（续字节一律 ≥ 0x80）。续字节会被 `isAlnumASCII` 判成「非字母数字」直接跳过，所以既不会漏掉有效字符，也不会把半个汉字当字符比较。
  - **什么时候不安全**：只要需要「按字符」处理非 ASCII —— 统计字符个数、按字符反转、判断中文回文、按字符下标切片 —— byte 遍历就会把多字节字符拆开。此时要么 `for range s`（自动解码 UTF-8，下标是字节偏移），要么先 `[]rune(s)`。
  - 顺带记住：`range string` 给的是 `(字节下标, rune)`，不是 `(第几个字符, rune)`。
- 关键代码片段：

```go
// 只把 ASCII 大写字母转小写，数字和标点不会被误伤
func lowerASCII(b byte) byte {
	if b >= 'A' && b <= 'Z' {
		return b + ('a' - 'A')
	}
	return b
}
```
