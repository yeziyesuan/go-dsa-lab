# 14. 最长公共前缀

- 难度 / 类型：简单 · 字符串 / 纵向扫描
- 思路（一句话）：以 `strs[0]` 为基准一列一列往下比，第一列比不过去的位置就是答案。
- 复杂度：时间 O(S)（S 为所有字符串长度之和），空间 O(1)（返回的是原串的切片视图，不拷贝）
- 卡点：
  1. 先判 `len(strs) == 0`，否则 `strs[0]` 直接 panic（index out of range）。`nil` 切片同样要吃这一刀。
  2. 内层一定要先判 `i >= len(s)` 再取 `s[i]`，顺序写反就是越界 panic。
  3. 返回 `first[:i]` 而不是 `first[:i+1]`：第 i 列已经确定不同，不能算进前缀。
  4. 别忘了「所有列都比完」的收尾 `return first`（例如 `["abc","abc"]`）。
  5. 按字节扫描对多字节字符有隐患：`["中", "一"]` 在第 2 个字节就分叉，会返回 `0xE4 0xB8` 这样的「半个汉字」。要保证返回合法字符串得先 `[]rune`。
- Go 注意点：
  - 字符串切片 `s[i:j]` 共享底层数组，不产生拷贝 —— 所以返回公共前缀几乎零成本。
  - 比较用 `s[i]` 拿到的 `byte` 和字节字面量比就行，不要写 `string(s[i])`（那会额外分配一个字符串）。
  - Go 的字符串比较和索引都是按字节的，所以「按字节纵向扫描」写起来最自然；`strings.HasPrefix` 是另一种写法（逐串缩短基准），但会多做不少重复比较。
- 关键代码片段：

```go
for i := 0; i < len(first); i++ {
	for _, s := range strs[1:] {
		if i >= len(s) || s[i] != first[i] {
			return first[:i]
		}
	}
}
return first
```
