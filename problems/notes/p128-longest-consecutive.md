# 128. 最长连续序列

- 难度 / 类型：中等 · 哈希
- 思路（一句话）：全部数丢进 set 去重，只从「没有前驱 `num-1`」的起点往右数 `num+1`，全程取最长。
- 复杂度：时间 O(n)，空间 O(n)
- 卡点：一开始对每个数都往右数了一遍，写成 O(n²)；要理解**只从起点数**才降到 O(n)——被数过的数都有前驱、不会再次成为起点，所以每个数最多被访问一次。另一个坑是起点判据写成 `num+1`（方向反了）；空数组/单元素不需要特判，`best` 初值 0 自然覆盖。
- Go 注意点：value 用 `struct{}` 当集合；map 遍历是**无序**的，所以内层的连续性只能靠查表判断，绝不能依赖遍历顺序；Go 没有 `while`，用 `for { ... break }` 表示一直往右数。
- 关键代码片段：

```go
// 前置：v 已确认是起点（set[v-1] 不存在），只从起点往右数
cur, n := v, 1
for {
	if _, ok := set[cur+1]; !ok {
		break
	}
	cur++
	n++
}
```
