# 121. 买卖股票的最佳时机

- 难度 / 类型：简单 · 数组 / 一次遍历（也可看成最简 DP）
- 思路（一句话）：一趟遍历维护「历史最低价」，每天先用今天价格算一次利润并更新答案，再用今天价格更新最低价。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：两句的顺序不能反——必须先算利润再更新最低价，否则会出现「今天买今天卖」这种当日套利。`low` 的初值要取 `prices[0]`，给 0 或 `MaxInt` 都会算错（给 0 时价格全正会算出 `p` 本身的假利润）。空数组必须先 `return 0`，不然 `prices[0]` 越界 panic。最后 `profit` 初值取 0，因为「不交易」也是合法选择。
- Go 注意点：一趟遍历 + 两个变量就能做到 O(1) 空间，不要为了「看起来清楚」去开 `minPrices []int` 把空间写成 O(n)。不用引 `math` 包找哨兵值，直接拿 `prices[0]` 更省事。
- 关键代码片段：

```go
low := prices[0]
profit := 0
for _, p := range prices {
	if p-low > profit {
		profit = p - low
	}
	if p < low {
		low = p
	}
}
```
