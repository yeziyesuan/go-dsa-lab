# 3. 无重复字符的最长子串

- 难度 / 类型：中等 · 滑动窗口 + 哈希
- 思路（一句话）：右指针往前扫，用 map 记住每个字符最近出现的下标；一旦撞上窗口内的重复字符，就把左边界跳到「上次出现位置 + 1」。
- 复杂度：时间 O(n)（l、r 都只单向移动，每个字符最多被访问两次），空间 O(min(n, 字符集大小))
- 卡点：
  1. **左边界更新忘了取 max，导致回退** —— 本题的头号坑。必须写 `l = max(l, i+1)`，不能写 `l = i+1`：map 里的 `i` 可能是窗口左边之外的老下标，直接赋值会让 `l` 往左退，窗口混进重复字符，答案偏大。
     - 复现用例 `"abba"`：扫到最后一个 `'a'` 时 `last['a'] = 0`，而此刻 `l` 已经是 2，写成 `l = 0+1 = 1` 就退了一名，窗口变 `"bba"`，算出 3（正确 2）。
     - 同类用例还有 `"tmmzuxt"`（正确答案 5，写错会得到 4 之类）。
  2. map 里要存**下标**而不是「出现过没有」，否则没法知道左边界该跳到哪。
  3. 更新答案要用当前窗口长度 `r-l+1`，而且要在移动左边界**之后**算。
  4. 空串返回 0，别让 `best` 初始化成 1。
- Go 注意点：
  - 用 `map[byte]int` 而不是 `map[rune]int`：题目字符集是 ASCII（字母/数字/符号/空格），一个字符就是一字节，`byte` 当 key 更省内存也更快；用 `rune` 会多一次 UTF-8 解码。
  - 但按 byte 滑窗对多字节字符是「按字节去重」，返回长度也是**字节数**：`"中中"` 返回 3 而不是 1（测试里固定了这个事实）。要按字符处理必须 `range s` 或 `[]rune(s)`。
  - Go 1.21 起内置了 `max`/`min`，可以直接写 `max(l, i+1)`，不用自己定义辅助函数；等价显式写法是 `if i+1 > l { l = i + 1 }`。
  - `map[byte]int` 的零值不是「不存在」，读之前必须用 `i, ok := last[c]` 的 comma-ok 形式判断。
- 关键代码片段：

```go
if i, ok := last[s[r]]; ok {
	l = max(l, i+1) // 必须取 max，否则 "abba" 会回退左边界
}
last[s[r]] = r
if r-l+1 > best {
	best = r - l + 1
}
```
