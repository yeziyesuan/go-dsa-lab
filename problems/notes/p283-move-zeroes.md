# 283. 移动零

- 难度 / 类型：简单 · 双指针（快慢指针）/ 原地数组
- 思路（一句话）：快慢指针把非零元素依次覆盖到前面，扫完后从 `k` 到末尾统一填 0。
- 复杂度：时间 O(n)，空间 O(1)
- 卡点：最大的坑是**只覆盖、忘了补零**——`[0,1,0,3,12]` 会变成 `[1,3,12,3,12]`，尾部残留旧值。第二个坑是补零循环的边界写成 `i <= len(nums)` 越界 panic。第三个是全零数组：此时 `k` 始终为 0，补零循环要老老实实把整条切片填一遍，别加「`k == 0` 就提前返回」的优化。
- Go 注意点：函数无返回值，结果只能通过参数切片带出去，所以测试直接断言传入切片的内容即可。切片的长度不可变，`nums = append(nums, 0)` 只在函数内换了个切片头、调用方看不到，原地覆盖才是正解。`for range` 的 `v` 是副本，写回必须用 `nums[i] = ...`。Go 没有真值判断，`if nums[i]` 是编译错误。
- 关键代码片段：

```go
k := 0
for i := 0; i < len(nums); i++ {
	if nums[i] != 0 {
		nums[k] = nums[i]
		k++
	}
}
for i := k; i < len(nums); i++ {
	nums[i] = 0
}
```
